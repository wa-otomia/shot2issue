# shot2issue desktop (WIP)

Cross-platform desktop app (Tauri 2 + React) for **system-wide** screenshot capture → annotate → file as a GitHub / GitLab / YouTrack issue, triggered by a global hotkey. Styled after [curvault](https://github.com/wa-otomia/curvault).

**Status:** scaffolding in progress. See the [repo root README](../../README.md) and the implementation blueprint for the plan (monorepo refactor → shared core → Tauri shell → capture/hotkey/overlay → editor + upload → signed CI + auto-update).
